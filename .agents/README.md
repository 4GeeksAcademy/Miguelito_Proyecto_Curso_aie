# Reglas de desarrollo para agentes

Este directorio define reglas operativas que los agentes deben aplicar durante el desarrollo.

Reglas disponibles:

1. [Regla 1: Cambios minimos y enfocados](.agents/regla-1-cambios-minimos.md)
Alcance: siempre activa.

2. [Regla 2: Validacion obligatoria en TypeScript](.agents/regla-2-validacion-typescript.md)
Alcance: por patron de archivo (src/**/*.ts y packages/shared/**/*.ts).

3. [Regla 3: Modo diagnostico guiado](.agents/regla-3-modo-diagnostico.md)
Alcance: solicitada por el agente.
